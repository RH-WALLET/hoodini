A website can ask. Only you can spend.

The part of Hoodini that runs inside a trading site runs in that site's world, so anything a hostile page can make it send, it will send. That is why the extension does not decide what to trust by asking nicely. It grants a page an exact list of nine capabilities and refuses everything else at the boundary, including any ability to unlock a wallet or move funds.

Why the first click used to cost two seconds.

Before a trade can be priced, the extension has to work out which venue actually trades the token, asking every adapter in turn. Cold, that one step dominated everything else. Hovering a control now resolves the venue while the pointer is still travelling, so the click skips straight to quoting. Both figures below were measured against live chain state rather than estimated.

One button, wherever the token launched.

Robinhood Chain has several launchpads and they do not share an interface. Rather than asking you which one a token came from, every adapter is handed the address at once and answers whether it can trade it. The first to claim it wins, and the answer is cached, so this happens once per token.

0% is structural, not promotional.

Install

Hoodini is not yet on the Chrome Web Store. Until it is, build it from source, which is the more honest way to run a wallet anyway, because you can read what you are about to trust. 

// clone the repository, then
pnpm install
pnpm --filter @hoodini/extension build

Then open chrome://extensions, turn on Developer mode, choose Load unpacked, and select apps/extension/dist.
