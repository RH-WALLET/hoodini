What that means
Fee
Fee-taking router functions are left out of the code entirely, so adding a skim is a compile error rather than a decision someone can quietly make later.
Keys
Generated on your device, encrypted with scrypt and AES-GCM, decrypted only into memory, auto-locked when idle. They are never transmitted anywhere.
Backend
No server exists. The extension asks for one network permission — the public RPC — and the manifest that grants it is a file you can read.
Venues
Pons, flap.sh, Doppler and Uniswap sit behind a single interface, so a token is tradeable wherever it happened to launch.
Approval
A page can propose a trade. Only you can approve one, in extension UI a website cannot reach.
Where it runs
  • axiom.trade

  • x.com

Each host is listed explicitly in the manifest. No wildcards across domains, no access to every site you visit — the match list is the whole statement of where this extension can read.

Install

Hoodini is not yet on the Chrome Web Store. Until it is, build it from source — which is the more honest way to run a wallet anyway, since you can read what you are about to trust. 

// clone, then
pnpm install
pnpm --filter @hoodini/extension build

Then chrome://extensions → Developer mode → Load unpacked → apps/extension/dist.
