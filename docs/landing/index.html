Hoodini

Trade Robinhood Chain from the page you're already on.

A Chrome extension that puts buy and sell buttons directly on terminals, X, Telegram and DexScreener. Zero platform fee. Your keys never leave your device. There is no backend.

What that actually means

0% is structural

Fee-taking router functions are left out of the code entirely, so adding a skim is a compile error rather than a decision.

Keys stay put

Generated on your device, encrypted with scrypt + AES-GCM, decrypted only in memory, auto-locked when idle.

Nothing to trust

No server exists. The extension asks for one network permission — the public RPC — and you can check that yourself.

Every venue, one button

Pons, flap.sh, Doppler and Uniswap sit behind a single interface, so a token is tradeable wherever it launched.

Token

Not launched yet.

Always verify the contract address against an official channel before trading. Anyone can create a token with any name.

Install

Hoodini is not yet on the Chrome Web Store. Until it is, build it from source and load it unpacked — instructions are in the repository.
